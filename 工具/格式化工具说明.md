# 固定 Java 格式化工具

- google-java-format 1.28.0，AOSP 4 空格风格；现有 JDK 17.0.20 已运行验证。
- 官方发布：https://github.com/google/google-java-format/releases/tag/v1.28.0
- JAR：https://github.com/google/google-java-format/releases/download/v1.28.0/google-java-format-1.28.0-all-deps.jar
- 大小：3,613,619 字节。
- 官方 SHA-256：`32342e7c1b4600f80df3471da46aee8012d3e1445d5ea1be1fb71289b07cc735`（下载后已核对）。
- 1.29.0 起运行要求提高为 JDK 21，本项目固定 1.28.0，不升级共享 JDK。
- JAR Manifest 已包含 Add-Exports；包装脚本仍显式列出所需 javac 模块导出，离线运行。
- `格式化.ps1`：直接格式化；`格式化.ps1 -Check`：只检查，返回非零即失败。
- 范围：app main、androidTest 和 tests Java，排除清单逐项明确。默认不触碰 XML/Gradle/PowerShell 排版。
- JAR 仅为开发工具，不作为 Gradle implementation 依赖，不进入 APK。
- 使用官方 formatter 的输出，不手工调整长行。原始换行由 formatter 自身处理，Git 不做额外转换。
- Apache-2.0 及所含依赖的许可证保存在 JAR 的 META-INF/LICENSE、META-INF/LICENSE.txt 中，保持完整；提取副本见同目录 license 文件。
