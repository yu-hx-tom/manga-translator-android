# 漫画翻译助手 · Android

在手机上阅读、翻译漫画，也可以把译文修改好后导出保存。

支持网页漫画和本地图片，提供自动翻译、对白排版、逐段改字与导出功能。**当前发布版本：1.1.8。**

**[下载安装包](https://github.com/yu-hx-tom/manga-translator-android/releases/tag/v1.1.8)** · **[反馈问题](https://github.com/yu-hx-tom/manga-translator-android/issues)**

## 下载与安装

1. 打开上方下载页面，展开 **Assets**，下载 **`manga-translator-1.1.8.zip`**。
2. 在手机上解压，打开里面的 **`manga-translator-1.1.8.apk`** 安装。
3. 如果手机询问安装权限，允许当前用于安装的浏览器或文件管理器安装此应用。

适用于 **Android 10 及以上的 64 位 ARM 手机**。使用此前同签名版本的用户可以直接覆盖安装，不必先卸载。

注意：发布页里的 **Source code** 是源码，不能直接安装。普通使用者只需下载上面指定的安装包。

## 第一次使用

开始翻译前，需要准备你自己的翻译服务信息。应用本身不附送翻译账号、API Key 或免费额度。

1. 打开应用，进入浏览器菜单中的 **设置**。
2. 填写服务方提供的 **API 地址**和 **API Key**。API Key 是使用服务的密钥，不是登录密码。
3. 初次使用可选择 **文字翻译**，填写服务方支持的模型名称。也可以点 **读取模型列表**后选择；读取失败时仍可手动填写。
4. 点击底部 **保存并使用**，再返回漫画页面。

不熟悉的高级参数可以先保持默认。建议先翻译一页，确认连接和效果正常，再处理整章。经常切换服务时，可以把整套设置保存为预设。

## 翻译网页漫画

1. 在 **浏览器**中输入网址，打开想阅读的漫画章节。
2. 等待漫画图片加载出来，再点底部 **开始翻译**。
3. 查看译图和处理状态；需要中断时，点 **停止翻译**。
4. 如果只有某一页或某些段落没有成功，可以使用单页重试或缺失段落补试，无需一开始就重做整章。

不同网站的图片加载方式不同。遇到页面无法处理时，可以先让图片充分加载，或把图片保存后改用本地翻译。

## 翻译本地漫画

1. 切换到 **本地翻译**，导入图片、文件夹，或 **ZIP / CBZ** 漫画压缩包。
2. 按系统提示选择要导入的文件或文件夹。
3. 打开导入的项目，点击 **开始翻译**，完成后查看结果。

批量处理前，建议先用少量图片试译，并留出足够的手机存储空间。

## 改译文、调整字号与导出

想在翻译后继续改字，请先到 **设置 → 汉化工作台**，开启 **翻译时保存可编辑草稿**。此设置用于之后翻译的页面，会增加存储占用。

1. 进入 **汉化工具**，打开工程；也可以从浏览器会话或本地图片建立工程。
2. 在编辑页选中需要调整的文字段落，修改译文，或调整字体、字号、颜色、排版和位置。
3. 修改后点击 **保存**，再按需要导出图片或 **ZIP / CBZ**。

字号放大仍会受到气泡空间限制。若自动排版不合适，可以先检查译文是否过长，再在工作台中调整。

**文字翻译**适合需要检查和修改译文的情况。**图像翻译**直接生成译图，没有可逐段改字的文字层，但仍可以导出图片。

## 1.1.8 更新了什么？

这次主要改善 **“对话框很大，译文字号却明显偏小”** 的情况。自动排版会结合气泡内可用空间和译文长度选择字号，同时保留留白，并避开相邻文字。

升级后，请重新翻译之前有问题的页面来比较效果。已经保存或导出的旧图片不会自动变大。

## 常见问题

**没有 API Key，可以直接翻译吗？**

需要先配置可用的翻译服务。服务是否收费、支持哪些模型，应以服务方说明为准；停止任务前已发出的请求也可能计费。

**模型列表读取失败，或者一直翻译失败怎么办？**

先检查网络，以及地址、密钥、模型名称是否填写正确，确认服务账户仍有可用额度。模型列表读取失败不一定代表不能翻译，可以手动填写模型名称后试译一页。不同服务对文字翻译、图像翻译的支持可能不同。

**为什么有些原文没有清掉，或文字直接盖在原图上？**

遇到复杂背景或无法安全清除原文的区域，应用可能采用原位嵌字，或保留原文。可以在工作台中进一步调整；更清晰的原图通常也有帮助。

**直接覆盖在原图上的文字，颜色怎么改？**

到 **设置 → 强行嵌字 → 文字颜色**选择颜色，再点 **保存并使用**。默认是黑字并保留白色描边。此设置用于之后生成的译图，不会批量改写已保存工程和旧图片。

**为什么工作台不能修改某一页的文字？**

请检查翻译前是否开启了可编辑草稿，以及是否使用文字翻译。图像翻译结果或未保存可编辑草稿的页面，不能直接逐段改字。

## 图片与服务

文字区域检测在手机上进行，但完整翻译需要联网，相关图片裁切会发送给你设置的翻译服务。请使用自己信任的服务，不要把 API Key 放进公开截图或问题反馈中。

反馈问题时，请描述操作步骤、应用版本和看到的报错；如果愿意提供图片示例，只提供可公开分享的内容。
