# 漫画翻译助手 · Android

Android 漫画阅读与翻译工具，基于 1.0.9 源码整理。原生 Java 界面，使用系统 WebView 浏览漫画网站，通过本地 ONNX 模型检测文字区域，再调用用户自行配置的兼容接口翻译和嵌字。

**本仓库不提供任何 API Key、账号、可用翻译接口地址或免费额度。API 地址、密钥及模型名称默认全部为空，需要用户在应用设置中填写。** 普通网站链接与 `example.com` 占位地址不是翻译服务。

## 功能

- 内置网页浏览器：地址与搜索输入、搜索历史、常用网站编辑与排序。
- 网页漫画图片翻译、指定单页重试、缺失段落补试与译文缓存。
- 本地漫画导入、阅读、批量处理及汉化工程导出。
- 离线文字区域检测、保守去字和中文排版；可编辑汉化工作台。
- 可配置并发、超时、重试、提示词及文字/图像模型。
- API Key 使用 Android Keystore 加密保存在用户设备上。

本地检测不等于全流程离线翻译。执行翻译时，文字区域裁切会发送给用户配置的服务；图像模式也会发送待处理裁切。请自行选择信任的服务并确认费用及内容使用权限。

仅发布源码、构建配置与合成输入检查，不提供 APK。私人配置、签名密钥、运行日志、缓存、漫画图片、历史试验数据以及检测模型权重均不在仓库中。仓库从干净的初始提交创建，不携带本地开发历史。

## 构建

要求 JDK 17、Android SDK Platform 36、Build Tools，以及 Gradle 9.4.1（Android Gradle Plugin 9.2.0）。最低 Android 10 / API 29，target SDK 35；ABI 为 arm64-v8a、armeabi-v7a、x86_64。

1. 配置 `JAVA_HOME` 和 `ANDROID_HOME`，或用 Android Studio 配置 SDK。
2. 将已获授权且兼容的检测模型放到 `app/src/main/assets/detector.onnx`。模型文件已被 `.gitignore` 排除；当前模型的尺寸和校验值见 `DetectorModels.java`。替换模型时还需核对输入输出、预处理和解码逻辑，不能只改文件名或哈希。
3. 执行 `./gradlew assembleDebug`，Windows 使用 `gradlew.bat assembleDebug`。首次构建需要联网获取 Gradle 和 Maven 依赖。
4. APK 位于 `app/build/outputs/apk/debug/`。调试签名由本机构建环境生成，不附带原开发者签名；不能保证覆盖安装此前的个人测试 APK。

构建脚本会阻止缺失模型或意外打包额外 ONNX 模型。没有模型时的构建失败是预期行为。

## 使用

打开设置，自行填写 API 地址、Key 和模型名称，再保存。文字模式默认使用兼容 Chat Completions 的服务，特定服务与模型组合使用 Responses 协议；图像模式使用图像编辑协议，具体请求字段见 `ApiClient.java`。并非所有标注“兼容”的服务都支持全部参数。应用不会替用户创建账号或附送接口。

网页受跨域、Canvas、登录状态及网站实现影响，不能保证任意漫画站都可处理。原图不足、检测遗漏或背景复杂时，清理与排版可能需要在工作台中人工调整。

## 检查

`python tests/check_source.py`：使用 JDK 17 编译并运行不联网的队列检查，检查开源默认配置和常见敏感文件规则。它不是完整的秘密扫描器，也不验证翻译服务。

`app/src/androidTest/` 包含设备侧检查源码，运行需要实际安卓设备和完整构建条件。本次开源发布没有完成安卓仿真或手机端翻译效果验证，不以构建通过代替运行验收。
